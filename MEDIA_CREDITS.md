# Media credits

## Photographs

All photographs in `public/media/photos/` come from Wikimedia Commons under free licences (CC BY, CC BY-SA).
They were found with `scripts/media/fetch-candidates.mjs` (licence filter: CC0, CC BY, CC BY-SA, public domain; files tagged as AI-generated excluded; second pass limited to recent photos) and chosen by eye.
The files were only resized and converted to WebP. On the site a light CSS grade (slight desaturation and contrast) is applied at display time; the files themselves are not retouched. CC BY-SA images remain under CC BY-SA.

On the site they illustrate **places**, never the fictional stories: every caption says so, and `/credits` lists them. Any archive image is shown in monochrome with an "Archive · year" label (the system is in place; no archive image is currently used).

## Brand motion

`public/media/motion/` holds the LËK Network ident (v1 concept): `lek-ident-16x9.mp4` (1920×1080, 30 fps, 6 s, H.264, silent), `lek-ident-720p.mp4` (web) and `lek-ident-end.webp` (final frame, used as the static version and as a poster).
It is built only from the approved logo artwork (`lib/ident.ts` copies the paths of `public/brand/lek-horizontal-light.svg`) plus brand-drawn lines; timing is in `components/ident.css`. It contains no news footage and no AI imagery.
Re-render it with the **Brand motion render** GitHub Action (`scripts/brand/render-ident.mjs`), which steps the CSS animation frame by frame and encodes with ffmpeg.

## Brand artwork

The logo files in `public/brand/` and the abstract SVG covers (`components/Cover.tsx`) belong to LËK Network.
The horizontal logo files' frame (viewBox) was enlarged so the word “Network” is no longer cut off; the artwork itself is unchanged.
